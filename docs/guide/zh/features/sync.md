# 云同步

支持 **Git / WebDAV / SFTP / S3 / SMB 五种云同步模式**，加密同步 uniTerm 设置：Git 模式使用您自己的私有仓库（GitHub / GitLab / Gitee），WebDAV 模式对接任意标准 WebDAV 服务，SFTP / SMB 模式复用您已有的服务器，S3 模式对接任意 S3 兼容对象存储。数据安全完全由您掌控。

![云同步](/imgs/cloud_sync_light.webp)


## 快速配置

### 1. 创建私有仓库 + 访问令牌

#### GitHub

**创建私有仓库：** 登录 GitHub → 右上角 `+` → New repository → 输入仓库名 → 选择 **Private** → Create repository。

**生成访问令牌：** Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：
- Repository access：选择 **Only select repositories**，选择刚创建的私有仓库
- Permissions → Contents：设为 **Read and write**
- 生成后复制令牌（仅显示一次）

#### GitLab

**创建私有仓库：** 登录 GitLab → New project → Create blank project → 输入项目名 → Visibility Level 选 **Private** → Create project。

**生成访问令牌：** Settings → Access Tokens → Add new token：
- Token name：输入名称
- Select scopes：勾选 **api** 或至少勾选 **read_repository** + **write_repository**
- 生成后复制令牌（仅显示一次）

#### Gitee

**创建私有仓库：** 登录 Gitee → 右上角 `+` → 新建仓库 → 输入仓库名称 → 选择 **私有** → 创建。

**生成访问令牌：** 右上角头像 → 设置 → 私人令牌 → 生成新令牌：
- 权限勾选 **user_info** 和 **projects**
- 生成后复制令牌（仅显示一次）

#### WebDAV

WebDAV 模式无需创建仓库，准备好一个 WebDAV 服务即可：

- **服务地址**：支持 Nextcloud、坚果云、InfiniCloud 等提供 WebDAV 的网盘，或自建服务，地址需包含协议与端口
- **账号**：该服务的用户名与密码（应用密码）

#### SFTP

SFTP 模式复用任意可 SSH 登录的服务器：

- **服务器地址**：`host[:port]` 格式，端口默认 22
- **账号**：该服务器的用户名与密码

#### S3

S3 模式对接任意 S3 兼容对象存储（AWS S3、MinIO、Cloudflare R2 等）：

- **Endpoint**：如 `https://s3.amazonaws.com`
- **Access Key / Secret Key**：该对象存储的访问密钥
- **Bucket**：存储桶名称（必填）
- **Region**：区域，如 `us-east-1`
- **URL 风格**：Virtual-hosted 或 Path，按服务商要求选择

#### SMB

SMB 模式对接 Windows 共享文件夹或 NAS：

- **服务器地址**：`host[:port]` 格式，端口默认 445
- **共享名**：SMB 共享目录名称（必填）
- **域**：可选，Windows 域名（如 `WORKGROUP`）
- **账号**：该服务的用户名与密码

### 2. 配置 uniTerm

1. 打开设置 → 云同步，点击「添加仓库」，选择同步方式 **Git / WebDAV / SFTP / S3 / SMB**
2. 按所选方式填写对应参数：Git 填仓库地址、用户名（可选）、访问令牌；WebDAV 填服务器地址（含协议与端口）、用户名、密码；SFTP 填服务器地址（`host[:port]`）、用户名、密码；S3 填 Endpoint、Access Key / Secret Key、Bucket、Region；SMB 填服务器地址（`host[:port]`）、共享名、用户名、密码
3. 设置一个**主密码**（用于加密数据，不会上传到仓库或网盘）
4. 点击确定，uniTerm 自动完成首次同步
5. 可在「同步范围」中按需勾选参与同步的数据

::: warning 注意
- 令牌和主密码请妥善保存，令牌仅显示一次
- 仓库必须设为私有，否则同步数据将公开可见
- 多设备同步时，每台设备填入相同的仓库地址、令牌和主密码
:::


## 同步操作

### 手动同步

点击「立即同步」按钮，uniTerm 会自动对比本地与远程的差异：
- **本地更新 → 推送到远程**（上传）
- **远程更新 → 拉取到本地**（下载）
- **无差异 → 已是最新**

### 自动同步

开启自动同步开关后：
- **启动时**自动同步一次
- **每次修改**连接、收藏、快捷命令、隧道、身份、代理后自动上传


## 同步内容

默认同步以下数据（加密后存储）：

- 连接列表与分组
- 连接收藏
- AI 配置（模型目录与自主轮次上限）
- 快捷命令
- SSH 隧道
- 密钥库身份
- 代理

可在「同步范围」中额外勾选（默认关闭）：

- **基本设置**（settings.json）：主题、路径、Shell、快捷键、界面布局等
- **AI技能**（skills.json）：完整同步用户技能——目录内容（SKILL.md、references/、scripts/）与启用/锁定/排序等偏好一起打包，新设备一次拉取即得完整技能。默认关闭的原因：技能可能包含多个文件、体积较大。技能体积上限为单文件 256KB、总计 4MB
- **AI命令**（commands.json）：完整同步用户命令——每个命令的 Prompt 模板（commands/*.md）与启用/锁定/排序等偏好一起打包。默认关闭的原因：命令内容因人而异，按需勾选
- **MCP 服务器**（mcp_clients.json）：同步外部 MCP 服务器配置（传输方式、启动命令、URL 等）。注意：请求头与环境变量中可能包含认证令牌，勾选即表示这些信息随同步数据加密传输

不同步的数据：

- 应用个性化设置（不勾选「基本设置」时，仅本机生效）
- AI 会话（仅本地）
- 云同步配置本身（每台设备独立配置）
- 终端历史记录

::: warning AI技能与AI命令同步说明
- 在另一台设备删除技能或命令后同步，该项不会从本机删除——同步不传播删除，避免误删本地数据（技能、命令、MCP 客户端均如此）
- 随应用分发的系统技能（`.system`）不参与同步，各设备保持随构建版本
:::


## 冲突处理

同步会先拉取远端再提交，两台机器交替使用时一般不会出现冲突。当多台设备同时修改同一数据且推送前未拉取最新版本时，uniTerm 会弹出冲突解决对话框，提供两种选择：

- **使用本地数据** — 以当前设备的数据为准，覆盖远程仓库
- **使用远程数据** — 以远程仓库的数据为准，覆盖当前设备


## 加密与安全

- **加密算法：** AES-256-GCM，每次加密使用随机 nonce
- **密钥派生：** 从主密码通过 PBKDF2-SHA256 算法派生加密密钥
- **密钥存储：** 派生密钥保存在操作系统密钥链中（Windows 凭据管理器 / macOS Keychain / Linux keyring）
- **零信任：** 所有数据在客户端加密后才上传，Git 服务端只看到密文


## 管理仓库

### 修改凭据

点击「编辑仓库」可修改用户名和访问令牌。仓库地址不支持修改（需先解除绑定再重新配置）。

修改凭据时会自动验证新令牌能否访问仓库、主密码能否解密远程数据。

### 修改主密码

点击「修改主密码」可更换加密密码。使用相同盐值重新派生密钥，重新加密所有数据并推送。

### 解除绑定

点击「解除绑定」将：
- 删除本地同步仓库
- 清除密钥链中保存的加密密钥和令牌
- 重置同步配置

> 远程仓库不会被删除，如需删除请前往 Git 服务平台手动操作。


## 同步状态

设置页面显示上一次同步的时间和状态：

- **成功**（绿色）— 最近一次同步正常完成
- **失败**（红色）— 显示具体错误信息（如网络超时、令牌失效等）
